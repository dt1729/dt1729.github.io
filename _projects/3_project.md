Multi-agent formation control for Unmanned Surface Vehicles (USVs) targeting search-and-rescue scenarios.

**Key contributions:**
- Implemented consensus-based controller for a fleet of 9 USV16 agents
- Hierarchical leader-follower architecture for coordinated search patterns
- Achieved **9× search area speedup** over single-agent baseline in VRX/Gazebo simulation

**Stack:** C++, ROS2, Gazebo (VRX), Python
